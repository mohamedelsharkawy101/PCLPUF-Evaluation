## System Requirements

The artifact has been tested on:

Software environment:
- Ubuntu 20.04.6 LTS
- Python 3.8
- Jupyter Notebook

Hardware environment:
- CPU: Multi-core x86 processor
- RAM: 32 GB recommended
- GPU: NVIDIA GeForce RTX 3090 (24 GB VRAM)
- NVIDIA Driver: 565.57.01
- CUDA Version: 12.7

GPU Requirements:
- NVIDIA GPU acceleration is used for Neural Network-based experiments.
- Logistic Regression and reliability-based attacks can be executed without GPU acceleration.
- Large-scale neural network experiments require a CUDA-compatible NVIDIA GPU with sufficient memory.
