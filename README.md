# PUF Split-Attack and Evaluation Repository

This repository contains notebooks and scripts for evaluating machine learning attacks on **Physical Unclonable Functions (PUFs)**, with a primary focus on PCL-PUF. It includes implementations of Logistic Regression (LR), Neural Network (NN), Reliability-based, and Split (Divide-and-Conquer) attacks, along with tools for dataset generation and attack evaluation.

The repository is intended to help researchers reproduce published attacks, compare modeling techniques, and evaluate different PUF configurations under varying experimental settings.

---

# Repository Contents

## `PCLPUF_Splitting_attack.ipynb`

Notebook implementing divide-and-conquer split attacks on **PC-LPUF** and **iPUF**.

* LR-based lower-stage modeling following **Wisiol et al. (CHES 2020)**.
* NN-based modeling for more complex lower-stage XOR configurations (e.g., **5,5**).
* Configurable challenge length, PUF architecture, dataset sizes, and attack parameters.


## `split_attack_record.py`

Utility script for recording split-attack performance.

* Records upper-stage accuracy after each refinement round.
* Exports results to CSV for analysis and visualization.

---

## `LR_attack_PCLPUF.ipynb`

Logistic Regression attacks on **PC-LPUF** and **XOR PUF**.

* Configurable challenge length, dataset size, and PUF architecture.

---

## `PCLPUF_Reliability_attack.ipynb`

Reliability-based attacks on **PC-LPUF** and **XOR PUF**.

* Implements reliability-based modeling attacks.
* Analyzes response reliability, flip rate, and correlation.
* Configurable noise level, dataset size, and PUF architecture.

---

## `NN_EVALUATION.ipynb`

Evaluates neural network attacks across multiple PUF architectures.

* Supports different MLP architectures and hyperparameters.
* Uses datasets generated by `NN_EVALUATED_PUFs.ipynb`.

---

## `NN_EVALUATED_PUFs.ipynb`

Generates datasets for:

* PC-LPUF
* iPUF
* XOR PUF
* REAP NVM

The generated datasets are used by `NN_EVALUATION.ipynb`.

---

# Typical Workflow

1. **Generate datasets** using `NN_EVALUATED_PUFs.ipynb`.

   * Manually configure the PUF architecture (e.g., challenge length, XOR stages, and other parameters) and regenerate the datasets required for the NN experiments presented in the paper.

2. **Evaluate Neural Network attacks** using `NN_EVALUATION.ipynb`.

   * Manually load the appropriate dataset generated in the previous step and configure the desired neural network architecture and hyperparameters.

3. **Run baseline Logistic Regression attacks on XOR and PCL-PUF** using `LR_attack_PCLPUF.ipynb`.

   * Manually configure the PUF architecture and training/testing dataset sizes before running the experiments.

4. **Perform split attacks on iPUF and PCLPUF** using `PCLPUF_Splitting_attack.ipynb`.

   * Adjust the PUF configuration, dataset sizes, and attack parameters to reproduce or extend the reported split-attack experiments.

5. **Record split-attack results for PCL-PUF** using `split_attack_record.py`.

   * Save the upper-stage accuracy after each refinement round for subsequent analysis and visualization.

6. **Evaluate reliability-based attacks on XOR and PCL-PUF** using `PCLPUF_Reliability_attack.ipynb`.

   * Configure the PUF architecture, noise level, and dataset sizes to reproduce the reliability-based experiments and analyses.

# Notes

* All notebooks expose configuration blocks that allow you to modify the PUF architecture, dataset sizes, and attack parameters.
* Some experiments require manually selecting or loading the appropriate generated datasets before execution.
* Large datasets and complex PUF configurations may require significant computation time and memory.
* The repository is intended to facilitate the reproduction and extension of published PUF attack experiments.
